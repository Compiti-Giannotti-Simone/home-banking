# Home Banking Backend

## How to Run

1. **Setup PHP Composer**:
   - Install Composer in your `/xampp/php` directory.

2. **Place Files**:
   - Copy the project files into your `/xampp/htdocs` directory.

3. **Install Dependencies**:
   - Open a terminal in the project directory and run:
     ```bash
     composer update
     composer install
     ```

4. **Start Services**:
   - Use XAMPP to start Apache and MySQL.

5. **Initialize Database**:
   - Open phpMyAdmin and execute the `init.sql` dump to set up the database schema and seed data.
